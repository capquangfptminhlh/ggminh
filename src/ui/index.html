Tạo hồ sơ đầu tiên để quản lý các phiên trình duyệt.

Tạo nhanh nhiều hồ sơ

Tạo 1–50 hồ sơ độc lập trong một lượt. Mỗi hồ sơ có phiên riêng; cấu hình mặc định là trình duyệt gốc và mạng trực tiếp. Gán proxy riêng trong Proxy Center.

Không tạo tài khoản Google, không nhập cookie và không chạy thao tác Google Ads.

Nhập hồ sơ hàng loạt từ CSV / TXT

Hỗ trợ CSV Excel, dấu phẩy / chấm phẩy / tab, tối đa 200 hồ sơ và 256 KB. Cột name bắt buộc. Cột còn lại: group, engine, startUrls, tags, notes, proxyType, proxyHost, proxyPort. Tách nhiều URL hoặc tag bằng ký tự |.

Không nhập mật khẩu, cookie, token, 2FA hoặc thông tin tài khoản. Proxy chỉ lưu địa chỉ; cần kiểm tra và quản lý mật khẩu riêng trong Proxy Center.

Xem trước để kiểm tra dữ liệu trước khi nhập.

Chưa chọn hồ sơ

Chỉ thay đổi nhãn phân loại; không tác động vào phiên đăng nhập, proxy hoặc dữ liệu trình duyệt.

Thùng rác hồ sơ — lưu 30 ngày

Hồ sơ trong thùng rác không mở được. Dữ liệu phiên, cookie và lịch sử trong thư mục profile được giữ nguyên cho đến khi xóa vĩnh viễn hoặc hết 30 ngày. Dữ liệu hết hạn được dọn khi phần mềm khởi động hoặc khi bạn bấm dọn.

Đang tải…

Xóa vĩnh viễn sẽ xóa dữ liệu trình duyệt cục bộ của hồ sơ này và không thể khôi phục bằng thùng rác. Nên sao lưu cấu hình trước nếu cần.

Cập nhật hồ sơ từ CSV

Sửa tối đa 200 hồ sơ trong một lượt. Cột id bắt buộc, có thể sửa name, group, tags, notes, startUrls. Chỉ cập nhật những cột được đưa vào file. Tag và URL phân tách bằng dấu |. Để trống tags/notes để xóa nội dung. Các hồ sơ đang chạy phải được đóng trước.

Không thay đổi trình duyệt, cấu hình proxy, cookie, tài khoản hay mã xác thực. Kiểm tra toàn bộ dữ liệu trước khi lưu.

Chọn hoặc dán CSV để xem trước.

Quản lý cửa sổ đang chạy

Chọn hồ sơ ở bảng để thao tác; nếu chưa chọn, sử dụng danh sách cửa sổ đang chạy. Chỉ ảnh hưởng tới các trình duyệt mà LHM đã mở trên máy Windows này (tối đa 10 cửa sổ).

Đang đọc danh sách...

Hồ sơ đang đóng: khởi chạy tại URL trên. Hồ sơ đang mở: tạo tab mới bằng giao diện DevTools cục bộ, chỉ hỗ trợ Chromium đã mở sau khi bật Local API. Tối đa 10 hồ sơ; không đồng bộ click/nhập liệu.

Synchronizer · Đồng bộ tab (thử nghiệm)

Chỉ đồng bộ chuyển trang HTTPS từ tab chính sang các cửa sổ phụ bằng tab mới; tối đa 15 lần. Không sao chép click, nhập liệu, cookie, form hoặc tham số URL. Cần bật Local API.

Chỉ chuyển tên, nhóm, engine, tags và mã hồ sơ đã mã hóa đầu-cuối; KHÔNG đồng bộ cookie, tài khoản, mật khẩu, token, URL, fingerprint hoặc phiên đăng nhập. Máy chủ HTTPS và token phải được cấp riêng cho từng người dùng.

Chưa kết nối. Chỉ dùng máy chủ được bạn tin cậy.

Khôi phục chỉ cập nhật metadata; profile đang mở sẽ bị từ chối. Profile mới được tạo trống, không mang theo cookie, mật khẩu hay phiên.

Tiện ích Chromium cục bộ

Chọn thư mục extension Manifest V3 đã giải nén trên máy. Chỉ dùng tiện ích tin cậy vì extension có thể đọc dữ liệu website theo quyền đã cấp. LHM không kiểm tra độ an toàn của mã nguồn.

Để gán hoặc bỏ extension, chọn tối đa 50 profile Chromium đang đóng trong bảng hồ sơ trước khi mở mục này. Không hỗ trợ Firefox, ZIP hay tải trực tiếp từ Chrome Web Store.

Lưu ý: Chrome/Edge bản mới có thể bỏ qua tham số tải extension. Vì vậy khả năng extension chạy thực sự cần thử trên trình duyệt được cài trên máy.

Dọn cache trình duyệt cục bộ

Chọn tối đa 20 hồ sơ ở bảng trước khi mở mục này. Chỉ xóa các thư mục cache được phép của những hồ sơ đã đóng. Không xóa cookie, mật khẩu, tiện ích, LocalStorage hoặc IndexedDB.

Số byte là ước lượng, có thể bị giới hạn khi có quá nhiều file. Việc xóa cache không thể hoàn tác; cần đóng trình duyệt để tránh làm hỏng dữ liệu. Kiểm tra và sao lưu khi cần.

Câu trả lời sẽ hiển thị ở đây. Nội dung không được tự động đưa vào workflow.

LHM không tự gửi dữ liệu trình duyệt, cookies, mật khẩu, token, tên hồ sơ hay proxy host. Không chia sẻ thông tin nhạy cảm trong câu hỏi. Model có thể trả lời sai; hãy xác minh trước khi áp dụng.

Snapshot phiên trình duyệt mã hóa

Sao lưu và khôi phục dữ liệu phiên cục bộ từ profile đã đóng, tối đa 32 MB và 1.200 file mỗi snapshot. Snapshot chứa thông tin đăng nhập và cookie đã mã hóa bằng mật khẩu tự đặt; tuyệt đối không chia sẻ file hoặc mật khẩu. Không đồng bộ cloud.

Có thể xuất file snapshot đã mã hóa ra ổ lưu trữ khác và nhập lại cho đúng profile ID/engine; file sẽ không chứa dữ liệu phiên ở dạng đọc được. Bạn phải tự bảo vệ file và mật khẩu, ứng dụng không tải lên cloud. Khôi phục thay thế toàn bộ phiên hiện tại; nên tạo snapshot trước. Mật khẩu lưu trong trình duyệt có thể bị ràng buộc với Windows cũ.

Tạo Profile Mới

Gecko đang ở chế độ thử nghiệm, mở bằng Firefox cài trên máy. Bản browser engine độc lập thương hiệu LHM cần được build riêng.

Gecko hỗ trợ sử dụng thủ công và proxy HTTP/SOCKS5 không mật khẩu. CDP/RPA chưa được hỗ trợ.

Chọn một mục đã lưu để điền thông số. Để quản lý kho, dùng nút Proxy Center trên thanh công cụ.

Kiểm tra IP thoát bằng HTTPS qua api.ipify.org, so sánh IP trực tiếp nếu có thể. Proxy HTTP có mật khẩu: tạo trong Proxy Center, sau đó gán từ danh sách hồ sơ.

Thông số gốc không dùng extension can thiệp fingerprint. Không có tùy chọn nào bảo đảm Google không liên kết các tài khoản.

Các giá trị tùy chỉnh dưới đây chỉ là thử nghiệm, không chứng minh tính tương thích hoặc ẩn danh.

Tự động hóa RPA & Kết nối API

LHM Ads Browser tích hợp sẵn Local REST API (Port 50325) hỗ trợ một số endpoint AdsPower. Phải bật API và gửi header X-API-Key cho mọi yêu cầu.

import requests
from playwright.sync_api import sync_playwright

PROFILE_ID = "pb_xxxxx"  # Điền ID profile của bạn
API_URL = f"http://127.0.0.1:50325/api/v1/browser/start?user_id={PROFILE_ID}"
API_KEY = __import__('os').environ['LHM_API_KEY']

# 1. Gọi LHM Ads Browser khởi chạy profile
res = requests.get(API_URL, headers={'X-API-Key': API_KEY}).json()
ws_endpoint = res["data"]["ws"]["puppeteer"]

# 2. Kết nối Playwright qua CDP WebSocket
with sync_playwright() as p:
    browser = p.chromium.connect_over_cdp(ws_endpoint)
    page = browser.contexts[0].pages[0] if browser.contexts[0].pages else browser.new_page()
    page.goto("https://ads.google.com/")
    print("Page Title:", page.title())
    # ... Thực hiện tự động hóa của bạn ...

import requests
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

PROFILE_ID = "pb_xxxxx"
API_URL = f"http://127.0.0.1:50325/api/v1/browser/start?user_id={PROFILE_ID}"

res = requests.get(API_URL, headers={'X-API-Key': API_KEY}).json()
debug_port = res["data"]["debug_port"]

chrome_options = Options()
chrome_options.add_experimental_option("debuggerAddress", f"127.0.0.1:{debug_port}")

driver = webdriver.Chrome(options=chrome_options)
driver.get("https://google.com")
print("Connected successfully via Selenium!")

const puppeteer = require('puppeteer-core');

async function run() {
  const profileId = 'pb_xxxxx';
  const res = await fetch(`http://127.0.0.1:50325/api/v1/browser/start?user_id=${profileId}`, { headers: { 'X-API-Key': process.env.LHM_API_KEY } });
  const data = await res.json();
  const wsEndpoint = data.data.ws.puppeteer;

  const browser = await puppeteer.connect({ browserWSEndpoint: wsEndpoint });
  const page = (await browser.pages())[0] || (await browser.newPage());
  await page.goto('https://ipinfo.io');
  console.log('Connected via Puppeteer!');
}
run();
