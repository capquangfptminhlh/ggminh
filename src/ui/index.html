Tạo nhanh nhiều hồ sơ

Tạo 1–50 hồ sơ độc lập trong một lượt. Mỗi hồ sơ có phiên riêng; cấu hình mặc định là trình duyệt gốc và mạng trực tiếp. Gán proxy riêng trong Proxy Center.

Không tạo tài khoản Google, không nhập cookie và không chạy thao tác Google Ads.

Nhập hồ sơ hàng loạt từ CSV / TXT

Hỗ trợ CSV Excel, dấu phẩy / chấm phẩy / tab, tối đa 200 hồ sơ và 256 KB. Cột name bắt buộc. Cột còn lại: group, engine, startUrls, tags, notes, proxyType, proxyHost, proxyPort. Tách nhiều URL hoặc tag bằng ký tự |.

Không nhập mật khẩu, cookie, token, 2FA hoặc thông tin tài khoản. Proxy chỉ lưu địa chỉ; cần kiểm tra và quản lý mật khẩu riêng trong Proxy Center.

Xem trước để kiểm tra dữ liệu trước khi nhập.

Tạo Profile Mới

Gecko đang ở chế độ thử nghiệm, mở bằng Firefox cài trên máy. Bản browser engine độc lập thương hiệu LHM cần được build riêng.

Gecko hỗ trợ sử dụng thủ công và proxy HTTP/SOCKS5 không mật khẩu. CDP/RPA chưa được hỗ trợ.

Chọn một mục đã lưu để điền thông số. Để quản lý kho, dùng nút Proxy Center trên thanh công cụ.

Kiểm tra IP thoát bằng HTTPS qua api.ipify.org, so sánh IP trực tiếp nếu có thể. Proxy HTTP có mật khẩu: tạo trong Proxy Center, sau đó gán từ danh sách hồ sơ.

Thông số gốc không dùng extension can thiệp fingerprint. Không có tùy chọn nào bảo đảm Google không liên kết các tài khoản.

Các giá trị tùy chỉnh dưới đây chỉ là thử nghiệm, không chứng minh tính tương thích hoặc ẩn danh.

Tự động hóa RPA & Kết nối API

LHM Ads Browser tích hợp sẵn Local REST API (Port 50325) hỗ trợ một số endpoint AdsPower. Phải bật API và gửi header X-API-Key cho mọi yêu cầu.

import requests
from playwright.sync_api import sync_playwright

PROFILE_ID = "pb_xxxxx"  # Điền ID profile của bạn
API_URL = f"http://127.0.0.1:50325/api/v1/browser/start?user_id={PROFILE_ID}"
API_KEY = __import__('os').environ['LHM_API_KEY']

# 1. Gọi LHM Ads Browser khởi chạy profile
res = requests.get(API_URL, headers={'X-API-Key': API_KEY}).json()
ws_endpoint = res["data"]["ws"]["puppeteer"]

# 2. Kết nối Playwright qua CDP WebSocket
with sync_playwright() as p:
    browser = p.chromium.connect_over_cdp(ws_endpoint)
    page = browser.contexts[0].pages[0] if browser.contexts[0].pages else browser.new_page()
    page.goto("https://ads.google.com/")
    print("Page Title:", page.title())
    # ... Thực hiện tự động hóa của bạn ...

import requests
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

PROFILE_ID = "pb_xxxxx"
API_URL = f"http://127.0.0.1:50325/api/v1/browser/start?user_id={PROFILE_ID}"

res = requests.get(API_URL, headers={'X-API-Key': API_KEY}).json()
debug_port = res["data"]["debug_port"]

chrome_options = Options()
chrome_options.add_experimental_option("debuggerAddress", f"127.0.0.1:{debug_port}")

driver = webdriver.Chrome(options=chrome_options)
driver.get("https://google.com")
print("Connected successfully via Selenium!")

const puppeteer = require('puppeteer-core');

async function run() {
  const profileId = 'pb_xxxxx';
  const res = await fetch(`http://127.0.0.1:50325/api/v1/browser/start?user_id=${profileId}`, { headers: { 'X-API-Key': process.env.LHM_API_KEY } });
  const data = await res.json();
  const wsEndpoint = data.data.ws.puppeteer;

  const browser = await puppeteer.connect({ browserWSEndpoint: wsEndpoint });
  const page = (await browser.pages())[0] || (await browser.newPage());
  await page.goto('https://ipinfo.io');
  console.log('Connected via Puppeteer!');
}
run();

Kiểm tra chỉ dùng lệnh --version với chương trình tìm được, không mở website hoặc đăng nhập tài khoản.

Kiểm tra cách ly dữ liệu cục bộ
Chưa chạy kiểm tra. Chỉ kiểm tra việc tách thư mục lưu trữ, không kiểm tra danh tính Google.

Đây chỉ là kiểm tra cấu hình: binary, URL, proxy, engine và User-Agent. Không khẳng định vô danh hoặc tránh bị phát hiện. Để đo IP thoát, bấm Kiểm tra proxy trong phần sửa hồ sơ.

Sao lưu cấu hình LHM

Sao lưu AES-256-GCM gồm cấu hình hồ sơ và quy trình Automation Studio. Không sao chép cookie, phiên đăng nhập, mật khẩu proxy và nội dung các bước tự điền. Ghi chú và URL tự nhập có thể chứa thông tin riêng tư: chỉ chia sẻ tệp sao lưu với người được phép. Nhập lại sẽ tạo hồ sơ mới, không ghi đè dữ liệu cũ.

Quên mật khẩu sẽ không giải mã được tệp. Không nên sử dụng mật khẩu Google.
